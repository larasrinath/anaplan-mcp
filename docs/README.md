# Integration documentation

This repository documents the Anaplan Integration API v2 server and its 70 MCP tools.

- [Integration API reference](api/Integration_API.md): published endpoints and request/response examples.
- [Tool and workflow guide](guides/anaplan-tool-guide.md): tool selection, prerequisites and execution sequences.
- [Remote deployment](guides/deploying-remote.md): HTTP setup, authentication and troubleshooting.
- [Runtime architecture](architecture/overview.md): request flow, components and trust boundaries.
- [Project setup](../README.md): local installation, configuration and supported operations.

The API reference is a documentation snapshot. The tool guide and implementation define this server's supported operations.
